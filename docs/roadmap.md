# Roadmap

## Phase 1: POC baby-foot
Coin acceptor (simulated) -> ESP32 -> Wi-Fi -> MQTT -> broker.

## Phase 2: Console
Timer for a fixed session length (configurable, e.g. 10 min). Publish start, end and duration.

## Phase 3: Dashboard
Node-RED (or ThingsBoard): games per day, console sessions, usage hours per device, estimated revenue, live device state, peak hours.

## Phase 4: Generalization
Add billiard and PCs, make one reusable device template, test with realistic traffic.
